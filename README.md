# 📱 Electronics Store Web Application

## Overview

This project is a full-stack web application for selling electronic devices. It has both **frontend** and **backend** components:

* **Frontend:** ReactJS with Material-UI (MUI)
* **Backend:** Spring Boot (Java)

The project demonstrates the use of **design patterns** like Strategy, Factory, Observer, and more, and implements **user** and **admin** functionalities.

---

## Features

### User Features

* Browse products by category
* Search and filter products
* View product details
* Add products to shopping cart
* Place orders
* View order history and order status
* Update profile information
* ...

### Admin Features

* Manage products (add, update, delete products)
* Manage categories
* Manage users (view users, ban/unban accounts)
* Manage orders (view, update status)
* Generate sales and inventory reports
* Dashboard to monitor site activity
* ...

### Design Patterns Implemented

* **Strategy:** For pricing, discounts, and promotion strategies.
* **Factory:** For creating product objects, order processing, and payment handlers.
* **Observer:** For notifying users of order status updates and stock changes.
* **Singleton:** For shared services like configuration management, logging, and database connections.
